# P.LAB CUP 2026 – Court Testing

Two static pages for captains:

- `index.html` — book (or change) a company's 1-hour court-testing session.
- `plan.html` — the live floor plan: which company is on which court, in each session.

Bookings are handled by a private Google Sheet behind a small Apps Script endpoint. No booking or captain
details are stored in this repository, and the floor plan shows company names only.
